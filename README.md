# 🚀 Estudos Full Stack

Repositório dedicado aos meus estudos, exercícios e projetos durante minha jornada de aprendizado em desenvolvimento Full Stack.

O objetivo é construir uma base sólida em desenvolvimento web, desde os fundamentos de HTML, CSS e JavaScript até desenvolvimento de APIs, bancos de dados, autenticação, testes, Git, deploy e arquitetura de aplicações.
