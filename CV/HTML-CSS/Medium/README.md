## 📖 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos de **Desenvolvimento Web**, tendo como referência visual a plataforma **Medium**.

A proposta foi reproduzir a estrutura visual de uma página semelhante, utilizando os conhecimentos adquiridos nas aulas de **HTML5 e CSS3**.

O projeto foi desenvolvido passo a passo, permitindo praticar desde a estruturação dos elementos HTML até a estilização e organização visual da página.

> 📌 Este projeto possui finalidade educacional e foi desenvolvido como exercício de aprendizado.

## 🎯 Objetivos

O principal objetivo deste projeto foi colocar em prática os conhecimentos adquiridos durante os estudos de HTML e CSS.

### Principais conceitos trabalhados

* Estruturação de páginas com HTML5;
* Organização de elementos;
* Classes e IDs;
* Estilização com CSS3;
* Posicionamento de elementos;
* Construção de barra de navegação;
* Criação de cabeçalho;
* Organização da área de conteúdo;
* Utilização de imagens;
* Utilização de arquivos SVG;
* Utilização de fontes;
* Organização de arquivos e pastas;
* Integração entre HTML e CSS.

## 📚 Desenvolvimento

O projeto foi construído em etapas durante as aulas.

### 1. Barra de navegação

Foi criada a estrutura da barra de navegação superior, trabalhando a organização dos elementos e sua estilização utilizando CSS.

### 2. Cabeçalho

Foi desenvolvida a seção de cabeçalho, organizando os principais elementos visuais e textuais da página.

### 3. Área de conteúdo

Foi criada a área principal da página, trabalhando a organização dos conteúdos, textos, imagens e demais elementos.
