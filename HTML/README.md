# 🚀 Estudos Full Stack

Repositório criado para acompanhar minha evolução durante o curso de **Desenvolvimento Web Full Stack**, reunindo aulas, exercícios, práticas e projetos desenvolvidos ao longo da formação.

O repositório será atualizado progressivamente conforme avanço pelos diferentes módulos do curso, funcionando como um registro da minha jornada de aprendizado em desenvolvimento **Front-end e Back-end**.

---

## 🎯 Objetivo

Construir uma base sólida em desenvolvimento Full Stack, passando pelos principais conceitos e tecnologias utilizados no desenvolvimento de aplicações web modernas.

O foco deste repositório é:

* Praticar programação através de exercícios e projetos;
* Consolidar os fundamentos de desenvolvimento web;
* Registrar minha evolução durante o curso;
* Desenvolver projetos progressivamente mais completos;
* Criar uma base para atuação como desenvolvedor Full Stack.

---
